## Course Overview

DP-300 is a Microsoft course for database administrators who want to run SQL workloads in the cloud and earn the **Microsoft Certified: Azure Database Administrator Associate** credential.

You already know T-SQL. Now learn to **deploy, secure, monitor, automate and recover** Azure SQL Database, Azure SQL Managed Instance and SQL Server on Azure VMs, in live labs on a real Azure subscription.
